# Alloy

Alloy is an all-in-one internal software solution designed to streamline and centralize various internal operations and employee engagement.

## Features

- **Internal Chats** - Real-time messaging and communication between employees
- **Product/Tasks Management** - Track projects, assign tasks, and manage workflows
- **Employee Management** - Handle employee records, onboarding, and HR processes
- **Internal Polls & Voting** - Create and participate in company-wide polls and voting
- **Secret Santa** - Organize fun holiday gift exchanges
- **Video Calling** - Internal video calling for collaborations and interviewing new candidates
- _...and lots more!_

## Tech Stack

| Layer    | Technology |
| -------- | ---------- |
| Frontend | Vue        |
| Backend  | Go         |
| Database | PostgreSQL |
| Mobile   | Flutter    |
